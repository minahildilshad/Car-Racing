# Street Sprint

A self-contained car racing arcade game built with HTML, CSS and JavaScript. Dodge traffic, collect coins, and survive increasing speed.

## Play

Extract this ZIP and open index.html in a modern browser. Steer with arrow keys or A / D. On mobile, tap the left/right buttons or drag across the road. Press P or Escape to pause. One collision ends the run.

High scores are saved in the browser on this device. No internet, login, API key or installation is required.

## GitHub

Upload all extracted files into your repository root. Keep index.html at the root for static hosting such as GitHub Pages.

## Edit

All source is in index.html. No dependencies or build step are required.

## Vercel deployment

Extract this ZIP and upload all three files (`index.html`, `README.md`, and
`vercel.json`) into your GitHub repository root. Do not upload the ZIP itself.
Choose Application Preset Other, Root Directory `./`, and leave all build
settings overrides disabled. No environment variables are required. Click Deploy.

The configuration serves the static app directly with no install or build step.
